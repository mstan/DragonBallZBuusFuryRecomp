# Resource cheats

The Mods page provides three optional resource cheats for the original USA
revision: Unlimited Health, Unlimited Energy and Max Zeni. All start disabled.
Enable the feature you want, then press Play. Health and energy include the
matching maximum values so the current amounts remain within those limits.

Turning a feature off stops its repeated writes. It does not undo changes
already made to a native save. Use a separate save when trying cheats.

These data-only packages use the engine's CodeBreaker Advance interpreter;
they do not change the original ROM file. Code constants are from the
[USA CodeBreaker list](https://almarsguides.com/retro/walkthroughs/gba/games/dragonballzbuusfury/codebreaker/).
Device master codes are unnecessary for the host interpreter. Other code
families and arbitrary code entry are not included in this package.
